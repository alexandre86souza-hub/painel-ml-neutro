Ver passo a passo para criar o aplicativo
  1. Entre em developers.mercadolivre.com.br/devcenter com a sua conta e clique em Criar aplicação.
  2. Em URIs de redirect, cole a URI de redirect acima — exatamente como está, sem barra no final.
  3. Em URL de retornos de chamada de notificação, cole a URL de notificação acima.
  4. Em Fluxos OAuth, marque Authorization Code, Client Credentials e Refresh Token.
  5. Em Permissões, dê leitura e escrita pelo menos em Publicação e sincronização.
  6. Aceite os termos, resolva o reCAPTCHA e salve.
  7. Copie o App ID e a Chave secreta para o passo 2.

    Cópia de segurança

    Todos os dados do painel (vendas, pagamentos, custos, métricas e configurações) num só arquivo, copiado sozinho uma vez por dia.

    DIÁRIA
    Última cópia
    —
    Pasta
    —
    Cópias guardadas
    —
    Guardar fora deste computador e restaurar
    1. Para a cópia ir para a nuvem, escolha uma pasta do OneDrive (ou Google Drive). No Terminal, na pasta do painel: npm run backup -- --pasta "C:\Users\VOCÊ\OneDrive\Painel-ML"
    2. Guarde junto, num lugar seguro (gerenciador de senhas), uma cópia do arquivo .env: ele tem a chave que abre os segredos do banco. Sem ela a cópia volta inteira, mas é preciso reconectar as contas.
    3. Para voltar uma cópia: pare o painel (Ctrl+C) e rode npm run restaurar -- painel-AAAAMMDD-HHMM.sqlite. O banco atual fica guardado ao lado, com outro nome.
    4. A guarda mantém as 7 últimas cópias diárias, 1 por semana por 8 semanas e 1 por mês por 2 anos.

    Claude Code

    Pergunte em linguagem natural e consulte seus dados sem procurar tela por tela.

    MCP
    Estado
    —
    Pasta do projeto
    —
    Como ligar o Claude Code aos seus dados
    1. Conecte a sua conta do Mercado Livre no passo 3.
    2. Abra o Terminal e cole a linha acima.
    3. Na primeira vez, permita o servidor HN-Gestor-ML.
    4. Digite /mcp e confirme que HN-Gestor-ML aparece como connected.
    5. Pronto — é só perguntar em português.

    Exemplos: “quais foram meus 10 melhores produtos nos últimos 30 dias?” · “quem está na curva A?” · “o MLB123… está perdendo visitas?”

    Para deixar a ponte somente em consulta, escreva ML_MCP_ESCRITA=0 no arquivo .env e reinicie.

    03 · SEGURANÇA

    Acesso ao painel

    Controle a senha utilizada para acessar esta instalação.

    Protegido
    ●

    Senha do painel

    Trocar a senha encerra as sessões abertas. Mínimo de 12 caracteres, com letra, número e caractere especial; vale por 365 dias.

    Trocar senha

    Mínimo de 12 caracteres, com letra, número e caractere especial (ex.: ! @ # $ % - _ .).

    ●

    Verificação em duas etapas

    Todo login pede a senha e o código de 6 dígitos do aplicativo autenticador do celular.

    Trocar de celular

    Confirme a senha e o código do celular atual. Em seguida o painel mostra uma chave nova para cadastrar no celular novo.

    Perdeu o celular? No computador do painel, rode npm run desativar-2fa.
