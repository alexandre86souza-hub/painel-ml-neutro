Amazon Ads

Conexão da sua conta de anúncios patrocinados da Amazon com o painel. Por enquanto esta tela só conecta e testa; campanhas e histórico do Ads da Amazon entram na próxima etapa. Precisa do acesso à Amazon Ads API aprovado.

1Endereço de retorno

No developer.amazon.com → Login with Amazon → engrenagem do seu perfil de segurança → Web Settings → Allowed Return URLs, cole este endereço e salve:

—

É o endereço do túnel do painel. Ele só muda se o painel for encerrado com "npm run parar"; se mudar, atualize lá também (e a URL do aviso de privacidade).

2Perfil de segurança

  1. No mesmo lugar, clique em Exibir ID do cliente e segredo do cliente.
  2. Cole aqui o ID do cliente e o Segredo do cliente. Ficam só neste computador; o segredo é guardado cifrado.

3Conta de anúncios

Clique em conectar, entre com o mesmo e-mail da Amazon e autorize. O painel volta para esta tela sozinho.
